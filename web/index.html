READING THE GRAPH

Methodology & limits

Shock order describes when labels were observed. Correlation edges summarize the 90 days before the event. These descriptive patterns do not establish causal transmission.

Hourly

Uses the dataset’s saved shock labels and shows each completed candle at its close time.

Daily

Uses an event-specific 95th-percentile absolute-return threshold calculated only from pre-event history. This is a visualization rule, not the calibrated hourly model label.

Edges

Undirected absolute-return correlation over the prior 90 days. An edge is not evidence that one asset caused another to move.
